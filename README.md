# Конфигурация «Управление груминг-салоном»

## Описание проекта
Конфигурация разработана для автоматизации оперативного учёта, CRM-процессов, работы с клиентами и расчёта заработной платы в салоне груминга. 

Проект создан в рамках итоговой практической работы во время обучения на курсе «1С-разработчик» в Яндекс Практикуме. Основная цель — с нуля спроектировать архитектуру приложения на платформе «1С:Предприятие 8.3», реализовать учёт услуг и списания материалов, настроить механизмы повторных продаж через задачи исполнителям и организовать интеграцию с внешними системами по HTTP API.

### Стек технологий и механизмов
* **Платформа:** 1С:Предприятие 8.3 (Управляемое приложение)
* **Язык разработки:** Встроенный язык 1С
* **Бизнес-логика и CRM:** Справочники, Документы, Регистры сведений и накопления, Задачи исполнителей (`ЗадачаИсполнителя`)
* **Безопасность и права:** Пользователи, Сеансы, Роли с разделением прав доступа на уровне объектов и RLS
* **Интеграция:** HTTP-сервисы (`GET /user`), HTTP-клиент для работы с внешним API (загрузка новостей)
* **Аналитика и UI:** Система компоновки данных (СКД), Пользовательские стили оформления форм, Подсистемы и картинки

## Выводы по результатам проекта
1. **Автоматизация CRM и повторных продаж:** Использование механизма «Задачи исполнителей» позволило исключить человеческий фактор при контроле повторных визитов — менеджер получает автоматическое напоминание на рабочий стол сразу после проведения услуги.
2. **Безопасность и гибкость прав:** Разграничение ролей (`Руководитель`, `Закупщик`, `Разработчик`) и применение RLS обеспечивают защищённость коммерческих данных и предотвращают непреднамеренные ошибки пользователей.
3. **Бесшовная интеграция:** Разработка собственных HTTP-сервисов и использование HTTP-клиента подтвердили возможность эффективного обмена данными между платформой 1С и сторонними веб-сервисами.

## Системные требования и инструкция по развёртыванию

### Системные требования
* **Платформа 1С:Предприятие:** версия 8.3.20 или выше (подходит учебная или рабочая версия).
* **Операционная система:** Windows 10/11, Linux или macOS.

### Инструкция по развёртыванию
1. Скачайте файл выгрузки информационной базы (`ГрумингСалон.dt`) из репозитория.
2. Запустите «1С:Предприятие» и нажмите кнопку **«Добавить...»**.
3. Выберите **«Создание новой информационной базы»** -> **«Создание информационной базы без конфигурации...»**.
4. Укажите название базы (например, *«Груминг-салон»*) и каталог на диске.
5. Запустите созданную базу в режиме **«Конфигуратор»**.
6. В меню выберите: **Администрирование** -> **Загрузить информационную базу...**
7. Укажите путь к скачанному файлу `1Cv8.dt` и подтвердите загрузку.
8. Перезапустите базу и войдите в режиме **«1С:Предприятие»**.
